# Estrategia de Financiamiento: Fondos CORFO (Enfoque AI-Driven)

Para ganar un **Semilla Inicia**, la palabra clave es **INNOVACIÓN**. Ahora que incorporamos IA, la postulación es mucho más sólida.

## 1. El Pitch de Elevador (AI-Centric)
"Somos el 'Darktrace' para las PYMEs de Latam. Usamos Inteligencia Artificial Generativa y Análisis de Comportamiento para democratizar la ciberseguridad avanzada, ofreciendo protección autónoma a empresas que no pueden pagar un equipo de expertos."

## 2. Componentes de Innovación (Para el Formulario)
*   **Problema**: Ciberseguridad tradicional es reactiva (espera la firma del virus). Las PYMEs no tienen expertos para configurar EDRs complejos.
*   **Solución**: Plataforma SaaS que usa **Modelos de Lenguaje (LLMs)** locales para interpretar ataques y **Machine Learning ligero** para detectar anomalías de comportamiento (ZTNA).
*   **Grado de Novedad**:
    *   No es solo "instalar software".
    *   Es innovación en proceso: Usar IA para reemplazar al Analista SOC Nivel 1.
    *   Uso de modelos Open Source soberanos (privacidad de datos).

## 3. Plan de Gasto del Subsidio (15 MM CLP)
El dinero ya no es para "dashboard", es para **Entrenamiento y Ajuste de Modelos**:
1.  **Hardware IA**: Compra de Workstation o créditos Cloud GPU para fine-tuning de modelos pequeños (Llama-3 / Mistral) especializados en logs de seguridad. (30% ppt).
2.  **Desarrollo Módulo IA**: Contratar dev python/data science por proyecto para integrar el "Risk Engine". (40% ppt).
3.  **Validación Comercial**: Pilotos pagados subsidiados para recopilar data real de ataques y re-entrenar el modelo. (30% ppt).

## 4. Diferenciación Competitiva
*   Consultoras Tradicionales: Venden horas hombre (caro/lento).
*   Software Enterprise (CrowdStrike/Darktrace): Impagable para PYME (USD 50k+).
*   **Nosotros**: IA que automatiza al experto, a precio de suscripción PYME.
